# Historia 3.1: Modelo de estación con proveedor y origen de medición

Estado: completada

## Historia

Como administrador de estaciones, quiero asociar cada estación a un proveedor
climático y conocer el origen de cada medición, para habilitar la ingesta externa
sin cambiar las reglas de dominio.

## Criterios de aceptación

1. `WeatherStation` admite `provider: none | openweather`, con `none` por defecto.
2. Se reutilizan las coordenadas de `Location`; no se duplican datos de ubicación.
3. `Measurement` admite `source: manual | openweather`, con `manual` por defecto.
4. Schemas y mappers son compatibles con documentos históricos sin esos campos.
5. DTOs, Swagger y cliente web exponen proveedor y origen.
6. La evaluación de umbrales y alertas no cambia según el origen.
7. Las pruebas cubren value objects, entidades, mappers y compatibilidad.

## Implementación consolidada

- [x] Value object `WeatherProvider`.
- [x] Enum `MeasurementSource`.
- [x] Persistencia, mappers y DTOs actualizados.
- [x] Valores por defecto compatibles con datos anteriores.
- [x] Pruebas unitarias y build de API.
