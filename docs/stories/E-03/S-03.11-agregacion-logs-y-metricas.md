# Historia 3.11: Agregación de logs y métricas

Estado: pendiente

## Historia

Como operador, quiero centralizar logs y métricas de los tres servicios, para
detectar fallas y medir el comportamiento técnico y de negocio.

## Criterios de aceptación

1. API, notificaciones e ingesta emiten logs JSON con `service`, correlación,
   `traceId` y `spanId` cuando estén disponibles.
2. Promtail envía logs a Loki y Grafana permite consultarlos.
3. Cada servicio expone `/metrics` para Prometheus.
4. Se instrumentan duración y cantidad HTTP, OWM, lotes de ingesta y RabbitMQ.
5. Existen métricas de negocio para mediciones ingeridas, alertas publicadas,
   errores OWM y estado de breakers.
6. El perfil Compose `observability` levanta Loki y Prometheus.
7. README documenta endpoints, consultas y etiquetas de cardinalidad controlada.
