# Historia 3.12: Trazabilidad distribuida desde ingesta hasta la cola

Estado: completada

## Historia

Como operador, quiero seguir una medición OWM en una única traza, para localizar
latencia y errores desde el polling hasta el procesamiento de notificaciones.

## Criterios de aceptación

1. Las tres aplicaciones inicializan OpenTelemetry y exportan por OTLP a Jaeger.
2. Se instrumentan HTTP, NestJS, MongoDB y RabbitMQ.
3. `traceparent` se propaga de ingesta a API.
4. El contexto se inyecta en headers AMQP y se extrae en notificaciones.
5. La traza cubre OWM → ingesta → API → persistencia → alerta → consumer.
6. Logs y spans comparten `traceId`.
7. Existe una prueba o procedimiento reproducible que demuestra la traza.

## Tareas

- [x] Configurar SDK, recursos y exportadores.
- [x] Propagar contexto HTTP y AMQP.
- [x] Correlacionar logs y validar una traza completa.

## Implementacion

- Las tres aplicaciones cargan OpenTelemetry al inicio del proceso:
  `weatherflow-api`, `weatherflow-ingestion` y `weatherflow-notifications`.
- El SDK exporta trazas por OTLP/HTTP a Jaeger y auto-instrumenta HTTP, NestJS,
  MongoDB y RabbitMQ.
- `ApiMeasurementSubmitterAdapter` conserva la propagacion HTTP automatica de
  W3C `traceparent` cuando ingesta llama a la API.
- `RabbitMqAlertPublisherAdapter` inyecta el contexto activo en headers AMQP.
- `RabbitMqClimateAlertConsumerAdapter` extrae esos headers antes de ejecutar
  el caso de uso de notificaciones.
- Los logs estructurados reutilizan el proveedor de contexto real y agregan
  `traceId`/`spanId` cuando hay un span activo.

## Procedimiento reproducible

1. Levantar el runtime con observabilidad:

   ```bash
   docker compose --profile observability up --build
   ```

2. Ejecutar un ciclo manual que pueda disparar alerta:

   ```bash
   curl -X POST http://localhost:3002/internal/ingestion/run \
     -H "x-ingestion-token: $INGESTION_SYSTEM_TOKEN"
   ```

3. Abrir `http://localhost:16686` y buscar trazas de
   `weatherflow-ingestion`, `weatherflow-api` o `weatherflow-notifications`.
   La traza esperada cruza OWM, ingesta, API, MongoDB, RabbitMQ y el consumer.
