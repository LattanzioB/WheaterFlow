# Historia 3.13: Pruebas de carga de consultas y reportes

Estado: pendiente

## Historia

Como desarrollador, quiero pruebas k6 reproducibles, para conocer el rendimiento
de consultas y reportes bajo distintos patrones de tráfico.

## Criterios de aceptación

1. Existe `npm run test:load` y configuración versionada.
2. Hay al menos tres escenarios: rampa sostenida, pico y carga prolongada.
3. Se cubren búsqueda de mediciones, temperatura actual y promedios.
4. Cada escenario define VUs, duración, ramp-up y dataset.
5. Hay umbrales de p95, tasa de error y throughput.
6. Las pruebas no dependen de OWM ni Telegram.
7. Los resultados JSON/HTML y un baseline se guardan en `docs/load-tests`.
