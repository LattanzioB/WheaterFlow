# Historia 3.13: Tests de carga para endpoints de consulta y reportes

Estado: borrador

## Historia

Como desarrollador,
quiero tests de carga automatizados sobre endpoints de consulta y reportes,
para demostrar comportamiento bajo tráfico concurrente de lectura con escenarios reproducibles.

## Criterios de aceptación

1. Framework integrado (Locust, Artillery, k6 o equivalente) con script npm.
2. Al menos tres escenarios distintos:
   - Búsqueda sostenida de mediciones con filtros (Entrega II).
   - Requests concurrentes de temperatura actual (S-03.9).
   - Carga mixta: búsqueda + promedios diario/semanal (S-03.10).
3. Tests contra API con dataset representativo (incluyendo historial OWM si disponible).
4. Cada escenario define usuarios virtuales, duración y ramp-up en config versionada.
5. Reporte con p95 latencia y tasa de error (umbrales documentados).
6. Sin dependencias externas OWM ni Telegram durante ejecución.
7. Resumen guardado en `docs/load-tests/`; README explica ejecución local.
