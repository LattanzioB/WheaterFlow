# Historia 3.14: Dashboard de monitoreo con métricas de negocio

Estado: borrador

## Historia

Como operador,
quiero un dashboard Grafana con paneles de hardware, endpoints y negocio,
para monitorear WeatherFlow y demostrar observabilidad en la presentación final.

## Criterios de aceptación

1. Grafana provisionado vía Compose con datasources Prometheus y Loki (S-03.11).
2. Grupo **Hardware / runtime**: CPU, memoria, reinicios de contenedores api/ingest/notifications.
3. Grupo **Endpoints**: tasa requests, errores, p95 por ruta API (incluyendo reportes).
4. Grupo **Negocio**:
   - Mediciones ingestadas/min (source OWM)
   - Alertas climáticas/hora
   - Tasa error OWM / estado circuit breaker
   - Throughput publish/consume RabbitMQ
5. JSON del dashboard versionado en `docs/observability/` o `grafana/dashboards/`.
6. Dashboard carga automáticamente con perfil observability.
7. README documenta URL e interpretación de paneles para demo.
