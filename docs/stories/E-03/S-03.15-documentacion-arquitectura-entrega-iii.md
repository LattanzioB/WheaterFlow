1. C4 muestra API, notificaciones, ingesta, OWM y observabilidad.

3. Hay secuencias para ingesta, alerta OWM y consulta de reportes.
4. Swagger documenta proveedor, origen, endpoint interno y reportes.
5. Se documentan las cinco estrategias de resiliencia y sus fronteras.
6. Se documentan logs, métricas, tracing, reglas de alertas y dashboard.
7. Se adjuntan resultados de carga y evidencia de al menos una semana de datos.
8. README explica arranque, configuración, URLs y recorrido de demo.
9. Diagramas, enlaces y referencias pasan las validaciones del repositorio.
