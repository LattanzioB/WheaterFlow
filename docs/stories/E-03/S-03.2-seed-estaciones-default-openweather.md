# Historia 3.2: Seed de estaciones default OpenWeather

Estado: borrador

## Historia

Como operador del sistema,
quiero tres estaciones meteorológicas default asociadas a OpenWeather con coordenadas válidas,
para que la ingesta periódica tenga ubicaciones de demo listas sin configuración manual.

## Criterios de aceptación

1. Un script de seed o migración crea tres estaciones default:
   - Universidad Nacional de Quilmes (UNQ)
   - Ciudad Autónoma de Buenos Aires (CABA)
   - La Plata, Buenos Aires
2. Las tres estaciones están configuradas con proveedor `openweather`, estado `active` y coordenadas verificadas.
3. El seed es idempotente (re-ejecutar no duplica estaciones default).
4. El script se integra en flujo de desarrollo documentado (`npm run seed` o equivalente).
5. Smoke test o aserción de integración verifica existencia de las tres estaciones tras seed.
