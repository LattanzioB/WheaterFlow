# Historia 3.4: Adaptador HTTP de OpenWeatherMap

Estado: pendiente

## Historia

Como servicio de ingesta, quiero consultar OWM mediante un puerto propio, para
desacoplar el caso de uso del contrato y transporte del proveedor.

## Criterios de aceptación

1. Existe el puerto `WeatherDataProvider`.
2. El adaptador consulta Current Weather API por latitud y longitud.
3. La respuesta se normaliza a una lectura con temperatura, humedad, presión,
   timestamp e identificador externo.
4. Las unidades se tratan explícitamente.
5. Errores HTTP y payloads inválidos producen errores tipados.
6. Hay fixtures y pruebas para éxito, 4xx, 5xx, timeout y respuesta inválida.
