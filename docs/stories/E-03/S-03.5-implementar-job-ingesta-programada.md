# Historia 3.5: Implementar job de ingesta programada

Estado: borrador

## Historia

Como servicio ingest,
quiero un job programado que consulte OWM para todas las estaciones OpenWeather,
para obtener lecturas externas de forma periódica y predecible según un cron configurable.

## Criterios de aceptación

1. `@nestjs/schedule` (o equivalente) ejecuta ingesta con expresión cron configurable vía `INGEST_CRON`.
2. El job carga estaciones con proveedor `openweather` desde la API (filtro de S-03.1).
3. Por cada estación, invoca el adaptador OWM (S-03.4) y recolecta lecturas (envío a API en S-03.6).
4. Fallos transitorios en una estación no abortan el batch; errores se loguean por estación con resumen final.
5. Existe endpoint de trigger manual o comando CLI para demo/debug.
6. Tests unitarios cubren registro de cron, iteración de estaciones y continuación ante fallo parcial.

## Tareas / subtareas

  - [ ] 1.1 Registrar cron desde `INGEST_CRON`.

  - [ ] 1.3 Iterar estaciones llamando `WeatherDataProvider`.

- [ ] Tarea 2: Trigger manual (CA: #5)
  - [ ] 2.1 Agregar endpoint admin o CLI para ejecutar un ciclo on-demand.

## Notas de desarrollo

- Depende de S-03.1 (filtro proveedor), S-03.4 (adaptador OWM).
- Cron sugerido: cada 10–15 minutos para acumular una semana de datos sin agotar free tier.
- Resiliencia avanzada (timeout, breaker) se agrega en S-03.7.
