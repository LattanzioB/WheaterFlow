# Historia 3.5: Proceso de ingesta programada

Estado: completada

## Historia

Como operador, quiero ejecutar ciclos periódicos de ingesta, para mantener
actualizadas las mediciones de las estaciones OpenWeather.

## Criterios de aceptación

1. El cron se configura mediante `INGESTION_CRON`.
2. El worker obtiene de la API las estaciones `provider=openweather`.
3. Consulta OWM para cada estación con concurrencia limitada.
4. Un fallo individual no cancela el resto del ciclo.
5. Cada ciclo informa éxitos, fallos, omitidas y duración.
6. Existe un trigger manual protegido para demostración y diagnóstico.
7. Las pruebas cubren cron, iteración y fallo parcial.

## Implementación

- La API expone `GET /internal/ingestion/stations`, protegido con el header
  `x-ingestion-token`, y filtra el catálogo por `provider=openweather`.
- `ApiWeatherStationCatalogAdapter` consume ese contrato sin importar entidades
  ni repositorios del servicio API.
- `IngestionScheduler` registra dinámicamente `INGESTION_CRON` al iniciar la
  aplicación y dispara `RunIngestionCycleService`.
- El caso de uso omite estaciones inactivas, limita consultas simultáneas a OWM
  mediante `OWM_CONCURRENCY_LIMIT` y captura los errores por estación para que
  el resto del lote continúe.
- Cada ejecución devuelve y registra un resumen con identificador de ciclo,
  origen (`scheduled` o `manual`), inicio, fin, duración, descubiertas, exitosas,
  fallidas, omitidas y detalle por estación.
- `POST /internal/ingestion/run` permite ejecutar el mismo caso de uso para
  demostración o diagnóstico. Requiere `x-ingestion-token` y responde `409` si
  ya existe un ciclo en curso.
- Las lecturas normalizadas se envían al puerto `MeasurementSubmitter`; S-03.6
  implementa el adaptador REST, la idempotencia y la persistencia por el
  pipeline de dominio de la API.

## Pruebas

- Registro del cron configurado.
- Consulta y validación del catálogo remoto.
- Límite efectivo de concurrencia.
- Continuidad ante fallo parcial y conteo de omitidas.
- Exclusión mutua entre ciclos y protección del trigger manual.
