# Historia 3.7: Resiliencia en la frontera OpenWeatherMap

Estado: pendiente

## Historia

Como operador, quiero proteger las llamadas a OWM, para que su latencia o caída
no agote recursos ni detenga la ingesta completa.

## Criterios de aceptación

1. El cliente OWM tiene timeout configurable.
2. Un circuit breaker abre y se recupera con umbrales documentados.
3. Un bulkhead limita consultas concurrentes por ciclo.
4. Un request cache conserva la última lectura válida por ubicación y TTL.
5. Si OWM falla, el sistema puede usar fallback controlado o saltear la estación,
   dejando explícita la antigüedad del dato.
6. Estado del breaker, cache hits/misses y fallos se exponen como métricas.
7. Las pruebas cubren timeout, apertura del breaker, bulkhead, cache y fallback.
