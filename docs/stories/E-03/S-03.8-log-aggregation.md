# Story 3.8: Log Aggregation — Structured JSON Logs + Loki/Promtail

Status: draft

## Story

As an operator,
I want structured, centralized logs across all services correlated with traces,
so that I can search and follow what happened across the distributed system from one place.

## Acceptance Criteria

1. All services (`api`, `notifications`, `ingestion`) emit structured JSON logs to stdout with consistent fields: timestamp, level, service, message, and contextual data.
2. Logs carry correlation identifiers: `traceId` and `spanId` (aligned with S-03.10) and, where applicable, `stationId`/`cycleId`.
3. Loki and Promtail are added to `docker-compose.yml`; Promtail ships container/stdout logs to Loki.
4. Logs are queryable in Grafana's Explore (Loki datasource provisioned).
5. Log levels are configurable per service via env (e.g. `LOG_LEVEL`).
6. Sensitive values (API keys, JWTs, secrets) are never logged.
7. Key domain/ingestion events are logged at appropriate levels: ingestion cycle summary, OWM failure/breaker transitions, alert published, notification dispatched.
8. A short runbook documents how to query logs in Grafana and how correlation ids tie logs to traces.

## Tasks / Subtasks

- [ ] Task 1: Structured logging (AC: #1, #2, #5, #6)
  - [ ] 1.1 Adopt a JSON logger (e.g. pino / Nest logger in JSON mode) across the services.
  - [ ] 1.2 Inject `traceId`/`spanId` and relevant context into log entries.
  - [ ] 1.3 Make `LOG_LEVEL` configurable; redact secrets.

- [ ] Task 2: Loki + Promtail (AC: #3, #4)
  - [ ] 2.1 Add `loki` and `promtail` services to `docker-compose.yml`.
  - [ ] 2.2 Configure Promtail to scrape container logs with service labels.
  - [ ] 2.3 Provision the Loki datasource in Grafana.

- [ ] Task 3: Event coverage (AC: #7)
  - [ ] 3.1 Ensure ingestion cycle, OWM failures/breaker, alert publish, and dispatch are logged.
  - [ ] 3.2 Use consistent level conventions (info/warn/error).

- [ ] Task 4: Docs (AC: #8)
  - [ ] 4.1 Write a brief log-query runbook for the architecture docs (S-03.14).

## Dev Notes

- Standardize the log schema across services so Loki labels/queries are uniform.
- Correlation depends on S-03.10 trace ids; if implemented first, leave the fields wired and populate them when tracing lands.
- Keep Grafana provisioning (datasources/dashboards) in a versioned `infra/observability` folder used by docker-compose.
